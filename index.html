把长链路拆成可确认的阶段

让失败停留在局部

明确 Agent 的职责与上下文传递规则，协同研发通过 Harness 连接自动执行和人工审核。保存会话、任务状态与产物，支持中断恢复和局部失败重试，保留可用资产，缩小返工范围。

按业务任务评测与配置模型

比较文本、视觉理解、图像和视频模型的剧情理解、结构化输出、角色与场景一致性、镜头连续性。结合人工标注、Bad Case、生成耗时和调用成本，为不同阶段及首帧、首尾帧、参考素材等生成模式配置模型。

把内容经验转化为校验规则

检查剧本结构、动作台词完整性、片段时长和站位连续性；引入 VLM 辅助评估角色、场景与参考图，结合提示词优化、有限重试和关键阶段人工审核，在后续生成前修正问题。

03 / 工作方法

先让它可用，
再验证它值得用。

01

把业务问题定义清楚

从内容团队、商家与产研的具体任务出发，明确使用场景、功能边界和验收标准，再决定 MVP 的优先级。

需求分析 / 产品规划 / PRD
02

让方案尽早运行起来

拆解 Agent 分工、工具能力与上下文传递。用 AI 编程推进可运行原型，在实际使用中发现流程与体验问题。

Agent / RAG / Vibe Coding
03

用可复测的反馈改进

分类问题案例，结合自动检查和人工复核验证质量；在相同条件下看响应与成本，决定下一轮改什么。

Eval / 人工复核 / 迭代决策

Agent 编排与模型评测

状态机、Harness、人工审核与任务恢复；按任务配置模型，以业务样例、人工标注和 Bad Case 推动质量迭代。

Multi-Agent / Harness / VLM / Eval

业务知识与工具落地

结合飞书沉淀业务知识与 Prompt 库，设计检索、上下文调用和结果校验；基于 Dify 搭建企业微信及 H5 场景的智能客服问答应用。

RAG / 飞书 / Dify / Skill

GEO 策略与流程复用

把品牌诊断、商业意图关键词、资料调研、内容改写、平台适配与检验反馈封装为半自动化 Skill。在固定问题集、统一测试条件下，目标品牌推荐率相对提升 20%。
